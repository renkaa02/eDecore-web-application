    About

    A transparent layout engine, not a black box

    eDecor is an interactive prototype for the Explainable AI Framework for Automated Interior Design, Lighting, and Space Utilization. This demo generates layouts with a transparent, rules-based engine that mirrors the reasoning of the SHAP-driven model described in the project — usable area, natural light, furniture density and room proportions each carry a visible, signed contribution to the score, so the "why" is never hidden behind the prediction.
